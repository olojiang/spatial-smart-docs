# Get started in 5 minutes

Walk through these five steps and you'll have the core of Spatial Smart down.

<Demo src="/media/zh/flow-switch-space-and-modules.mp4" caption="Select a space, then switch between the three modules" />

::: steps
1. **Sign in**
   Open the [platform](https://alpha.pinefield.cn/pinefield.spatial-smart/), enter your account, password, and the 6-digit captcha, then click **Sign in** (登 录). The captcha expires quickly — **click Refresh (换一个) first, then type it immediately**. → [Details](/en/guide/login)

2. **Select a space**
   Click "Select a space..." (请选择空间...) in the top-left corner, then search for and pick a space from the dropdown. When `encId` and `spaceName` appear in the address bar, you're set.

3. **Send your first message in Apps**
   Type a request in the large input box in the middle, such as "What can you help me with?", and press <kbd>Enter</kbd>. The code workbench opens on the right automatically. → [Start a conversation](/en/apps/chat)

4. **Create an agent**
   Switch to **Agents** (智能体), click **New agent** (新建智能体), choose **General** (通用), enter a name, and click **Create agent** (创建智能体). → [Create an agent](/en/agents/create)

5. **Explore an API service**
   Switch to **Services** (服务), click any service on the left, then look through **Overview / Code / Versions / Run logs** (总览 / 代码 / 版本管理 / 运行日志) on the right. → [Service workbench](/en/services/workbench)
:::

::: tip Tips
- Button grayed out? **Select a space first**, or type something in the input box.
- Want more room? Click **Collapse Application navigation** (折叠应用导航) in the top-left corner, or drag the dividers between panes.
- Site-wide search: the magnifier in the top-left corner searches messages across all conversations.
:::
