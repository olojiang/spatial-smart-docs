# Language and appearance

## Switch the interface language

The **中 / EN** button in the bottom-left corner switches between Chinese and English instantly, no reload required.

<Shot src="/media/zh/shell-english.png" caption="After switching to English: Apps / Agents / Services" />

- In Chinese, the button tooltip reads "切换到 English"; in English it reads "Switch to 中文".
- Only interface text is translated. **Names you've given spaces, services, conversations, and so on are not translated.**

Common interface terms:

| Chinese | English |
| --- | --- |
| 应用 / 智能体 / 服务 | Apps / Agents / Services |
| 新建服务 | New service |
| 服务开发 | Services development |
| 还没有选中服务 | No service selected |
| 总览 / 代码 / 版本管理 / 运行日志 | Overview / Code / Versions / Run logs |
| 固定标签页 | Pin tab |
| 折叠代码与预览 | Collapse Code and preview |
| 折叠应用导航 | Collapse Application navigation |
| 切换主题 | Toggle theme |

## Light / dark

The **☀ / ☾** to the right of the language button is the **Toggle theme** (切换主题) switch; it flips between light and dark across all three panes. The icon shows **the mode you'll switch to**: a moon in light mode, a sun in dark mode.

<Shot src="/media/zh/shell-dark.png" caption="Dark mode" />

::: tip
**Settings → General → Theme** (设置 → General → 主题) also offers **Gray** (灰色) and **Custom** (自定义).
:::

## Adjust the layout

- **Collapse Application navigation** (折叠应用导航): top-left button, hides the whole navigation pane.
- **Collapse Code and preview** (折叠代码与预览): top-right button, hides the workbench.
- **Drag the dividers**: resize the three panes.

See [Interface tour](/en/guide/interface) for details.
