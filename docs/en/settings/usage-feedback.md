# Usage and feedback

Both live in the **avatar menu** in the bottom-left corner.

<Shot src="/media/zh/shell-user-menu.png" caption="Avatar menu" />

## Monthly usage

The **Monthly usage** (月度用量) row in the menu shows this month's usage directly ("—" when there's no data yet). Click the **↗ external-link icon** on the right to open the Pinefield developer platform's usage page in a new tab for a detailed breakdown of calls and consumption.

## Feedback

Click **Feedback** (建议反馈) to open the Feishu Bitable form **"Manual bug report"** (人工提BUG) in a new tab. The form notes that when filing a bug manually, you only need to fill in the essentials; the triage, fix, and regression fields are completed later by AI or developers.

| # | Field | Required | What to enter |
| --- | --- | :-: | --- |
| 1 | Description (描述) | ✅ | A one-line summary of the problem |
| 2 | Symptoms (问题现象) | ✅ | What you saw (error text, unexpected behavior) |
| 3 | Expected result (预期结果) | ✅ | What you expected to see |
| 4 | Steps to reproduce (复现步骤) | ✅ | Numbered steps clear enough for someone else to reproduce |
| 5 | Evidence (证据材料) | | Screenshots or screen recordings (paste or drag to upload) |
| 6 | Test environment (测试环境) | | Browser, operating system, space name |
| 7 | Console/Network logs (Console/Network 日志) | | Log files exported from browser developer tools |
| 8 | Additional notes (补充说明) | | Any other context |
| 9 | Test account / prerequisites (测试账号/前置条件) | | The account used and any data needed beforehand |

::: tip Get it right the first time
Attach the **space ID** (copyable from the space dropdown) and the log file from **Export logs** (导出日志) in Settings — it greatly speeds up diagnosis.
:::

## Sign out

**Sign out** (退出登录) is the red item at the bottom of the avatar menu. See [Sign in and sign out](/en/guide/login).
