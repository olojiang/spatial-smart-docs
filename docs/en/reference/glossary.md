# Glossary

| Term | Chinese | Definition |
| --- | --- | --- |
| Space | 空间 | The top-level container, with a name and unique ID; all content belongs to a space |
| Space ID / encId | 空间 ID | The space's unique identifier (UUID), shown in the `encId` URL parameter |
| Workspace | 工作空间 | The project container in **Apps** that holds code generated by conversations |
| Conversation | 会话 / 对话 | One continuous exchange with the AI |
| Apps | 应用 | The module for building projects through conversation |
| Workbench | 代码工作台 | The Code / Preview / Space panel on the right |
| Pin tab | 固定标签页 | Pins additional panels to the workbench tab bar |
| Agent | 智能体 | An AI assistant that lives in a space and can run on its own |
| General agent | 通用智能体 | An agent you can chat with anytime |
| Scheduled agent | 定时智能体 | An agent that runs tasks automatically at a set frequency |
| Event-triggered agent | 事件触发智能体 | An agent that responds automatically when specified object types appear |
| Object type | 对象类型 | A category of data in a space, such as camera, space.zone, render.model |
| Background knowledge | 背景知识 | Business and domain context you give an agent |
| Responsibilities | 职责 | The work an agent is meant to do |
| MCP | MCP | Model Context Protocol — a standard that lets AI call external tools and data |
| Skill | Skill | A reusable AI capability, invoked with `/skill-name` |
| Service | 服务 | An API endpoint generated from a conversation |
| Draft | 待发布草稿 | A changed service version that isn't live yet |
| Rollback | 回滚 | Restoring a service to a previous version |
| Take offline | 下线 | Stop serving the current version |
| Run logs | 运行日志 | A record of every endpoint call |
| Web search | 联网 | Lets the AI search the internet while answering |
| SSO | SSO | Single Sign-On — Pinefield's unified sign-in |
