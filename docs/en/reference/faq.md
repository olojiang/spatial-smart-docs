# FAQ

## Sign-in

::: details I keep getting "User does not exist / wrong password / wrong captcha" (用户不存在/密码错误/验证码错误)
Nine times out of ten, the captcha expired. Fill in your account and password first, click **Refresh** (换一个), then **immediately** enter the new captcha and sign in. If it still fails, check your password's capitalization. → [Sign in and sign out](/en/guide/login)
:::

::: details I get sent back to the sign-in page after signing in
Your session expired — just sign in again. If it keeps happening, clear your browser's cookies for `alpha.pinefield.cn` and try again.
:::

## Buttons and actions

::: details New agent (新建智能体), New service (新建服务), and the attachment button are grayed out
You haven't selected a space yet. Click "Select a space..." (请选择空间...) in the top-left corner and pick one. The attachment and send buttons are also gray while the input box is empty.
:::

::: details I can't click Create agent (创建智能体)
A required field is missing: General needs a name; Scheduled needs a task description; Event-triggered needs at least one selected object and "What to do when found" (发现后要做什么).
:::

::: details I can't click Create service (创建服务)
**Endpoint function** (接口功能) is required. The button becomes clickable once you fill it in.
:::

::: details My scheduled agent isn't running after creation
Scheduled agents **must be started after creation** before they run on schedule.
:::

## Conversations

::: details I can't find the conversation I just had
Conversations belong to the workspace they were created in. Conversations created with no space selected are under the **Default** (默认) workspace. You can also use 🔍 Global search in the top-left corner to search message content.
:::

::: details How do I stop the AI mid-reply?
While it's generating, the send button turns into a square **Stop** (停止) button — click it.
:::

::: details The model calls itself by a different name
Replies are generated by the underlying coding engine, so its self-introduction may not match the selected model name. The model shown below the input box is the one in use.
:::

## Services

::: details I changed the code, so why didn't the endpoint change?
Saving code only creates a **draft**. It takes effect only after you publish a new version in **Versions** (版本管理).
:::

::: details The new version has a problem. What now?
In **Versions**, find the previous version and click **Roll back to this version** (回滚到此版本).
:::

::: details What does the green dot mean?
The service is currently **Available** (可用): published and online.
:::

## Other

::: details How do I report a bug?
Avatar menu → **Feedback** (建议反馈), then fill in the form. Attaching the space ID and logs gets it resolved faster. → [Usage and feedback](/en/settings/usage-feedback)
:::
