# 常见问题

## 登录

::: details 一直提示「用户不存在/密码错误/验证码错误」？
九成是验证码过期。先填好账号和密码，再点「换一个」，**立刻**输入新验证码并点登录。仍失败再检查密码大小写。→ [登录与退出](/guide/login)
:::

::: details 登录后又跳回登录页？
登录状态过期了，重新登录即可。若反复出现，清除浏览器中 `alpha.pinefield.cn` 的 Cookie 后再试。
:::

## 按钮与操作

::: details 「新建智能体」「新建服务」、附件按钮是灰色的？
还没有选择空间。点左上角「请选择空间...」先选一个空间。附件和发送按钮在输入框为空时也是灰色的。
:::

::: details 「创建智能体」按钮点不了？
必填项没填：通用类型需要名称；定时类型需要任务描述；事件触发需要至少选择一个对象并填写「发现后要做什么」。
:::

::: details 「创建服务」按钮点不了？
「接口功能」是必填项，填写后按钮才会变为可点击。
:::

::: details 定时智能体创建后没有运行？
定时智能体**创建后需要启动**才会按计划运行。
:::

## 对话与会话

::: details 找不到刚才的会话？
会话归属于创建时所在的工作空间。未选空间时创建的会话在「默认」工作空间下；也可以用左上角 🔍 全局搜索消息内容。
:::

::: details 如何中途停止 AI 的回复？
生成过程中，发送按钮会变成方形「停止」按钮，点击即可。
:::

::: details 模型说自己是另一个名字？
回复内容由底层编码引擎生成，自我介绍可能与所选模型名称不同。以输入框下方显示的模型为准。
:::

## 服务

::: details 改了代码为什么接口没变化？
保存代码只会生成**待发布草稿**，需要在「版本管理」中发布新版本后才生效。
:::

::: details 新版本出问题了怎么办？
在「版本管理」中找到上一个历史版本，点「回滚到此版本」。
:::

::: details 绿色圆点是什么意思？
服务当前「可用」：已发布并在线。
:::

## 其他

::: details 如何反馈 Bug？
头像菜单 →「建议反馈」，按表单填写。附上空间 ID 和日志更快解决。→ [用量与反馈](/settings/usage-feedback)
:::
