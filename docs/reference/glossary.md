# 术语表

| 术语 | English | 解释 |
| --- | --- | --- |
| 空间 | Space | 最顶层的容器，有名称和唯一 ID；所有内容归属于某个空间 |
| 空间 ID / encId | Space ID | 空间的唯一标识（UUID），出现在地址栏 `encId` 参数中 |
| 工作空间 | Workspace | 「应用」中的项目容器，存放对话生成的代码 |
| 会话 / 对话 | Conversation | 与 AI 的一次连续交流 |
| 应用 | Apps | 通过对话开发项目的模块 |
| 代码工作台 | Workbench | 右侧的代码 / 预览 / 空间面板 |
| 固定标签页 | Pin tab | 把更多面板固定到工作台标签栏 |
| 智能体 | Agent | 常驻空间、可自动运行的 AI 助手 |
| 通用智能体 | General agent | 随时可对话的智能体 |
| 定时智能体 | Scheduled agent | 按频率自动执行任务的智能体 |
| 事件触发智能体 | Event-triggered agent | 发现指定对象类型时自动响应的智能体 |
| 对象类型 | Object type | 空间中的数据类别，如 camera、space.zone、render.model |
| 背景知识 | Background knowledge | 告诉智能体的业务与领域背景 |
| 职责 | Responsibilities | 智能体要完成的工作 |
| MCP | Model Context Protocol | 让 AI 调用外部工具和数据的标准协议 |
| Skill | Skill | 可复用的 AI 技能，可通过 `/skill-name` 调用 |
| 服务 | Service | 由对话生成的 API 接口 |
| 待发布草稿 | Draft | 已修改但尚未上线的服务版本 |
| 回滚 | Rollback | 把服务恢复到某个历史版本 |
| 下线 | Take offline | 停止对外提供当前版本 |
| 运行日志 | Run logs | 每次接口调用的记录 |
| 联网 | Web search | 允许 AI 在回答时搜索互联网 |
| SSO | Single Sign-On | 统一登录 |
