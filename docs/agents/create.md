# 新建智能体

<Demo src="/media/zh/flow-new-agent-types.mp4" caption="新建智能体：在通用、定时、事件触发之间切换" />

::: steps
1. 在顶部 [选择空间](/guide/space)（未选空间时按钮为灰色）。
2. 切换到 **智能体** 模块，点击左侧 **「新建智能体」**。
3. 在弹窗顶部选择类型：**通用 / 定时 / 事件触发**。
4. 按下文说明填写字段。
5. 点击 **「创建智能体」**。按钮短暂显示「创建中…」，随后弹窗关闭，右上角提示「智能体已创建。」，并自动打开新智能体。
:::

弹窗标题下方的说明是：「选择类型并填写配置，创建后加入当前空间。」

## 💬 通用

> 随时可对话的通用智能体。创建后常驻在空间中，你可以随时与它对话，它会根据你设定的职责来工作。

<Shot src="/media/zh/agent-new-general.png" caption="通用类型" />

| 字段 | 必填 | 说明 / 示例 |
| --- | --- | --- |
| 智能体名称 | ✅ | 给智能体起个名字，例如「客流顾问」 |
| 背景知识 | 选填 | 补充智能体需要了解的业务背景或领域知识 |
| 职责 | 选填 | 例如：分析数据趋势并生成每日摘要。不填会自动生成一段默认职责 |

底部提示：「创建后可在智能体列表中查看和管理」。**名称填写后「创建智能体」按钮才可点击。**

## ⏰ 定时

> 按时间自动执行任务。设定好任务和执行频率，智能体会按计划自动运行，无需你手动触发。

<Shot src="/media/zh/agent-new-scheduled.png" caption="定时类型" />

| 字段 | 必填 | 说明 / 示例 |
| --- | --- | --- |
| 智能体名称 | 选填 | 不填会自动生成名称 |
| 任务描述 | ✅ | 描述智能体需要定期执行的工作 |
| 运行频率 | — | 默认「每 30 分钟」 |

运行频率可选：

| 每 1 分钟 | 每 5 分钟 | 每 30 分钟（默认） | 每小时 | 每 3 小时 | 每 6 小时 |
| :-: | :-: | :-: | :-: | :-: | :-: |

::: warning
底部提示：**「创建后需启动才会按计划自动跑。」** 创建完成后别忘了启动它。
:::

## ⚡ 事件触发

> 发现新对象时自动响应。选择你关注的对象类型，再告诉智能体发现后要做什么，它会自动帮你处理。

<Shot src="/media/zh/agent-new-event.png" caption="事件触发类型" />

| 字段 | 必填 | 说明 / 示例 |
| --- | --- | --- |
| 智能体名称 | 选填 | 不填时自动命名为「对象 · 跟进」 |
| 你想关注的对象 | ✅ | 先用搜索框过滤（如 VIP、访客、告警），再点每行右侧的「选择」。**可多选，任意一个出现都会触发** |
| 发现后要做什么 | ✅ | 例如：自动整理关键信息并通知我。下方会实时显示「当 你选择的对象 出现时，智能体会自动：…」 |

当前可关注的对象类型（以平台显示为准）：

<Kv :rows="[
  ['空间', 'enclosure · origin · space.structure · space.zone'],
  ['摄像头', 'camera · camera.info'],
  ['形状', 'shape · rectangle'],
  ['渲染', 'render · render.config · render.layer · render.space · render.model · render.material · render.3dgs'],
  ['渲染变换', 'render.offset · render.rotation · render.scale · render.keyFrames'],
  ['环境', 'render.ambientLight · skybox'],
]" />

::: tip
「创建智能体」按钮要等到**至少选择一个对象**并且**填写了「发现后要做什么」**才会变为可点击。
:::
