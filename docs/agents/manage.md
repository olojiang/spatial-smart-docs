# 配置与试运行

在左侧列表点击一个智能体，中间是它的**配置**，右侧是**智能体预览**对话框。

## 顶部操作

| 按钮 | 作用 |
| --- | --- |
| **停止** / 启动 | 停止正在运行的智能体（停止后可再次启动） |
| **保存** | 修改配置后才可点击，保存你的改动 |
| **配置 / YAML** | 在表单视图与 YAML 文本视图之间切换 |

## 配置视图

<Shot src="/media/zh/agent-config.png" caption="配置视图" />

| 字段 | 说明 |
| --- | --- |
| 名称 | 修改这里即可**重命名**智能体 |
| 模型 | 默认「PF-H1-Auto（默认）」，下方显示「当前生效：PF-H1-Auto」 |
| 背景知识 | 智能体需要了解的业务、空间和领域背景 |
| 职责 | 智能体要做什么，例如「根据当前空间与项目上下文，为用户提供准确、可执行的建议。」 |
| 运行方式 | 只读，显示类型；类型只能在创建时选择 |
| 空间 ID / 智能体 ID | 只读，排查问题时可提供给管理员 |

## YAML 视图

适合批量修改或复制配置。说明文字：「可保存名称、角色、背景知识、职责和模型。触发器请在「配置」页编辑；Agent ID、空间 ID 不可通过 YAML 修改。」

<Shot src="/media/zh/agent-yaml.png" caption="YAML 视图" />

```yaml
agent:
  agent_id: "1de85ef1-…"          # 只读
  enclosure_id: "37143acf-…"      # 空间 ID，只读
  name: "文档示例智能体"
  role: "根据当前空间与项目上下文，为用户提供准确、可执行的建议。"
  background_knowledge: ""
  responsibilities: "…"
  model_name: "PF-H1-Auto"
```

## 与智能体对话（试运行）

右侧 **智能体预览** 显示「与 *智能体名* 连续对话 · 运行中」。

::: steps
1. 在底部输入框输入问题（<kbd>Enter</kbd> 发送，<kbd>Shift</kbd> + <kbd>Enter</kbd> 换行）。
2. 平台会通过 Seele 发起**真实试运行**；同一预览页会保持本次会话上下文。
3. 用 **历史会话** 查看以前的对话；用 **新建会话** 开始新的上下文（还没有会话时为灰色，提示「当前还没有会话」）。
:::

## MCPs、Skills 与 Skill 商店

点击工作台右上角 **＋（固定标签页）**，可以添加三个标签页：

<Shot src="/media/zh/agent-pin-menu.png" caption="固定标签页：MCPs / Skills / Skill 商店" />

| 标签 | 作用 |
| --- | --- |
| **MCPs** | 查看和管理智能体可用的 MCP 工具（外部能力接入） |
| **Skills** | 查看智能体已启用的技能 |
| **Skill 商店** | 浏览并添加新的技能 |

已添加的标签会从菜单中消失；三个都添加后菜单为空。

## 列表中的「操作」菜单

鼠标移到列表中的智能体上，右侧会出现圆形 **操作** 按钮：

<Shot src="/media/zh/agent-row-menu.png" caption="操作菜单：编辑配置 / 停止 / 删除 Agent" />

| 菜单项 | 作用 |
| --- | --- |
| 编辑配置 | 进入配置编辑 |
| 停止 | 停止该智能体 |
| 删除 Agent | ⚠️ 永久删除，不可恢复 |

::: danger 删除前请确认
删除智能体后无法恢复。共享空间（名称带「[勿删]」）里的智能体请勿随意删除。
:::
