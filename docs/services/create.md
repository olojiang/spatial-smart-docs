# 新建 API 服务

有三个入口都能打开「新建服务」：左侧服务树顶部的 **＋ 新建服务**、中间顶部的蓝色 **＋ 新建服务** 按钮、以及未选中服务时空状态里的 **新建服务**。

<Shot src="/media/zh/service-new.png" caption="新建服务弹窗" />

::: steps
1. 先 [选择空间](/guide/space)，切换到 **服务** 模块。
2. 点击任一 **新建服务** 入口。类型目前只有 **API 服务**：「对数据进行查询与调整的 API 接口」。
3. **服务名称**（选填）：不填则按功能自动命名。
4. **接口功能**（必填）：用一句话描述接口要做什么，例如「根据传入的起始时间和结束时间，返回人流折线图数据」。**填写后「创建服务」才可点击。**
5. **请求方式与路径**：请求方式可选 `POST`（默认）或 `GET`；路径默认 `/api/v1/new-service`，建议改成有意义的名字，如 `/api/v1/booth-flow`。
6. 点击 **创建服务**。
:::

::: tip 写好「接口功能」
把 **输入**、**处理逻辑**、**输出** 都说清楚，生成的接口会更准确：

> 根据传入的 **startTime、endTime（ISO 8601）**，从展位数据中抽取该时间范围内的人流数据，**按小时聚合**，返回 **折线图所需的 series 数组和总人数 total**。
:::

底部提示：「创建后可通过对话继续调整，在「版本管理」中发布上线」。

| 请求方式 | 何时使用 |
| --- | --- |
| `POST` | 参数较多、需要传数组或对象（推荐默认） |
| `GET` | 参数简单、只读查询，便于浏览器直接访问 |
