# 登录与退出

Spatial Smart 使用**松田统一登录（SSO）**。打开平台地址时，如果尚未登录，会自动跳转到登录页 `alpha.pinefield.cn/pinefield.sso`。

<Shot src="/media/zh/login-sso.png" url="alpha.pinefield.cn/pinefield.sso" caption="松田统一登录页：账号、密码、6 位数字验证码" />

## 登录步骤

::: steps
1. 在「账号」框输入你的用户名。
2. 在「密码」框输入密码。
3. 点击验证码图片旁边的 **「换一个」**，刷新出一张新验证码。
4. **立刻**把图片里的 6 位数字填入「验证码」框。
5. 点击 **「登 录」**。成功后会自动回到 Spatial Smart 主界面。
:::

::: warning 验证码有效期非常短
验证码几秒钟后就会失效，这是登录失败最常见的原因。正确节奏是：**先填好账号密码 → 点「换一个」→ 马上输入 → 马上点登录**。输错了就再点「换一个」重来，动作要快。
:::

## 登录失败怎么办

登录失败时页面只会显示一句话：**「用户不存在/密码错误/验证码错误」**，不会告诉你具体是哪一项错了。按这个顺序排查：

| 排查顺序 | 检查什么 | 怎么做 |
| --- | --- | --- |
| 1 | 验证码过期或看错 | 点「换一个」，看清后立即输入并登录 |
| 2 | 密码大小写 | 确认大写锁定没开，密码区分大小写 |
| 3 | 账号是否正确 | 账号区分大小写，注意不要带空格 |
| 4 | 账号是否开通 | 联系管理员确认账号已开通 Spatial Smart |

## 退出登录

::: steps
1. 点击左下角头像（显示你的用户名）。
2. 在弹出的「个人」菜单中点击红色的 **「退出登录」**。
:::
