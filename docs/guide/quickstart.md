# 5 分钟上手

跟着下面 5 步走一遍，你就掌握了 Spatial Smart 的核心用法。

<Demo src="/media/zh/flow-switch-space-and-modules.mp4" caption="选择空间，然后在三个模块之间切换" />

::: steps
1. **登录**
   打开 [平台地址](https://alpha.pinefield.cn/pinefield.spatial-smart/)，输入账号、密码和 6 位验证码，点「登 录」。验证码有效期很短，**先点「换一个」，再立刻输入**。→ [详细说明](/guide/login)

2. **选择空间**
   点击左上角「请选择空间...」，在下拉列表中搜索并选择一个空间。地址栏会多出 `encId` 和 `spaceName` 参数，说明选择成功。

3. **在「应用」里发出第一句话**
   在中间的大输入框里写下需求，例如「你能帮我做什么？」，按 <kbd>Enter</kbd> 发送。右侧会自动出现代码工作台。→ [发起对话](/apps/chat)

4. **创建一个智能体**
   切到「智能体」，点「新建智能体」，选择「通用」，填一个名字，点「创建智能体」。→ [新建智能体](/agents/create)

5. **看看一个 API 服务长什么样**
   切到「服务」，点左侧任一服务，右侧依次查看「总览 / 代码 / 版本管理 / 运行日志」。→ [服务工作区](/services/workbench)
:::

::: tip 小贴士
- 按钮是灰色的？**先选空间**，或者先在输入框里输入内容。
- 想要更大的工作区？点左上角「折叠应用导航」，或拖动栏与栏之间的分隔条。
- 全站搜索：左上角放大镜，可以搜索所有会话里的消息。
:::
