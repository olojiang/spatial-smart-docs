# 界面导览

Spatial Smart 是一个**三栏式工作台**：左边是导航，中间是对话或配置区，右边是工作台（代码、预览、标签页）。三栏之间都可以拖动调整宽度。

<Shot src="/media/zh/service-overview.png" caption="三栏布局：① 导航栏 ② 对话区 ③ 工作台" marks="10,40,1|38,40,2|80,40,3" />

## ① 左侧导航栏

| 位置 | 控件 | 作用 |
| --- | --- | --- |
| 左上角 | **折叠应用导航** | 把整个导航栏收起，中间与右侧区域变宽；再点「展开应用导航」恢复 |
| 顶部 | **Logo（✦）** | 回到「应用」模块 |
| 顶部 | **空间选择器**「请选择空间...」 | 切换当前空间，详见 [空间与切换](/guide/space) |
| 顶部 | **搜索（🔍）** | 打开「全局搜索」，搜索所有会话中的消息 |
| 中部 | **应用 / 智能体 / 服务** | 三大模块切换，蓝色下划线表示当前模块 |
| 中部 | 列表区 | 当前模块的会话、智能体或服务 |
| 底部 | **头像** | 个人菜单：设置、月度用量、建议反馈、退出登录 |
| 底部 | **中 / EN** | 切换界面语言，详见 [语言与外观](/settings/appearance) |
| 底部 | **切换主题（☀/☾）** | 在浅色与深色之间切换 |

## 全局搜索

点击左上角放大镜，打开 **全局搜索** 弹窗，可以搜索**所有会话中的消息内容**，支持关键字高亮和快速跳转。

<Shot src="/media/zh/shell-search.png" caption="全局搜索：输入关键字后出现时间和消息类型两组筛选" />

::: steps
1. 在输入框中输入关键字（输入前「搜索」按钮是灰色的）。
2. 可选：选择时间范围 —— 全部时间 / 最近 1 天 / 最近 7 天 / 最近 30 天。
3. 可选：选择消息类型 —— 全部消息 / 用户消息 / 助手消息。
4. 点击「搜索」。没有结果时会提示 `未找到包含 "关键字" 的结果`。
5. 点右上角 × 或按 <kbd>Esc</kbd> 关闭。
:::

## ② 中间区域

中间区域随模块变化：在「应用」中是对话流和输入框；在「智能体」中是智能体配置；在「服务」中是服务的对话记录。未选择内容时会显示提示，例如「还没有选中服务」。

## ③ 右侧工作台

右侧工作台由一排**标签页**组成，最右边有两个固定按钮：

- **＋ 固定标签页**：把更多面板固定为标签页（不同模块可选项不同）。全部固定后会显示「全部标签页已固定」。
- **折叠代码与预览**：收起整个工作台，让中间区域占满；再次点击（此时名为「展开代码与预览」）恢复。

## 拖动调整宽度

两条竖向分隔条可以用鼠标拖动：

- 导航栏 ↔ 中间区域：拖窄后，过长的名称会显示省略号。
- 中间区域 ↔ 工作台：调整对话与代码区的比例。

::: tip
导航栏处于折叠状态时，左侧分隔条无法拖动，请先展开导航栏。
:::
