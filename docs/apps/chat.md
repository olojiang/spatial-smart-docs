# 发起对话

「应用」是 Spatial Smart 的默认模块：你用自然语言描述需求，AI 在**工作空间**里帮你写代码、解释项目、生成页面。它就像一位坐在你旁边的工程师。

<Shot src="/media/zh/app-home.png" caption="应用首页：「从现在起，空间智能触手可及」" marks="5,13,1|51,48,2|42,58,3|47,58,4|80,58,5|84,58,6|87.5,58,7" />

| 编号 | 控件 | 说明 |
| --- | --- | --- |
| 1 | **新对话** | 开启一个全新的会话 |
| 2 | **输入框** | 描述你的需求；首页提示「搜索工作空间、创建工作空间、连接数据源... 请描述您的需求」 |
| 3 | **工作空间** | 选择对话所在的工作空间，或「＋ 新建」 |
| 4 | **附件（📎）** | 附加文件；空输入时为灰色不可用 |
| 5 | **模型** | 当前使用的大模型，默认 *Kimi K2.6* |
| 6 | **联网（🌐）** | 是否允许 AI 联网搜索，**默认开启**（蓝色高亮） |
| 7 | **发送** | 输入内容后可用；生成过程中变为「■ 停止」 |

## 发送第一条消息

<Demo src="/media/zh/flow-app-chat.mp4" caption="输入需求 → 回车发送 → AI 流式回复，右侧出现代码工作台" />

::: steps
1. （可选）先在左上角选择空间，再在「工作空间」菜单里选择或新建一个工作空间。
2. 在输入框写下需求，例如「你能帮我做什么？」。按 <kbd>Enter</kbd> 发送。
3. 你的消息出现在右上方；下方出现蓝色 ✦ 加载动画，**发送按钮变为方形「停止」**，随时可以中断生成。
4. 右侧自动打开 **代码工作台**，先显示「正在加载文件树…」，随后出现项目文件。→ [代码工作台](/apps/workbench)
5. 回复中会出现可折叠的 **「思考完成」** 标记，点开可查看模型的推理过程。
6. 回复结束后，会话自动以第一句话命名，并出现在左侧列表中。
:::

<Shot src="/media/zh/app-conversation.png" caption="一次完整的对话：左侧会话列表，中间回复，右侧代码工作台" />

## 继续对话的快捷语法

会话开始后，输入框提示变为：`输入消息... (@ 引用文件, / Slash Commands, $ Shortcut)...`

| 输入 | 作用 | 示例 |
| --- | --- | --- |
| `@` | 引用工作空间里的文件，让 AI 聚焦在某个文件上 | `@src/App.tsx 这里为什么报错？` |
| `/` | 调用 Slash 命令或已启用的 Skill | `/skill-name` |
| `$` | 使用快捷指令（Shortcut） | `$` 后按提示选择 |

::: tip 写好需求的 3 个要点
1. **说清目标**：要做什么页面 / 接口 / 功能。
2. **给出数据**：字段、示例值、数据来源。
3. **提出验收标准**：例如「做完后跑一下测试」。
:::

## 选择模型

点击输入框下方的模型名称，打开模型列表。顶部可以 **搜索模型**，也可以用 **筛选** 按钮过滤；当前模型以高亮背景显示。

<Shot src="/media/zh/app-model-picker.png" caption="模型选择器：支持搜索与筛选" />

当前可选的 20 个模型：

| 厂商 / 系列 | 模型 |
| --- | --- |
| 字节 豆包 | Doubao Seed Code |
| MiniMax | MiniMax M3 |
| 月之暗面 Kimi | Kimi K2.6（默认）、Kimi K2.7 Code、Kimi K3 |
| OpenAI GPT | GPT-5.2、GPT-5.2 Codex、GPT-5.3 Codex、GPT-5.4、GPT-5.5、GPT-5.6-luna、GPT-5.6-sol、GPT-5.6-terra |
| DeepSeek | DeepSeek V4 Flash、DeepSeek V4 Pro |
| 智谱 GLM | GLM 5.1、GLM 5.2、GLM 5.3、GLM 5.3 Flash |

::: info 怎么选？
写代码优先选带 **Code / Codex** 的模型；追求速度选 **Flash**；普通问答用默认的 Kimi K2.6 即可。模型列表以平台实际显示为准。
:::

## 工作空间菜单

点击输入框下方的 **「新工作空间 ⌄」**：上半部分是「最近工作空间」（没有时显示「暂无最近工作空间」），下半部分是 **「＋ 新建」**。

<Shot src="/media/zh/app-workspace-menu.png" caption="工作空间菜单：最近工作空间 + 新建" />

## 管理会话

- **会话列表**：左侧「应用」分组下按工作空间（如「默认」）归档，点击即可打开历史会话；每个工作空间行右侧的「＋」可在其中新建会话。
- **会话菜单**：会话标题旁的 **⋯** 提供 **重命名会话** 和 **会话设置**。
- **新对话**：左侧最上方「新对话」，随时开启新话题。

::: warning 注意
未选择空间时，新建的会话会归到「默认」工作空间。如果你在某个空间里工作，记得先选空间。
:::
