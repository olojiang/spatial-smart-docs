# 语言与外观

## 切换界面语言

左下角的 **中 / EN** 按钮可在中文与英文之间即时切换，无需刷新。

<Shot src="/media/zh/shell-english.png" caption="切换为英文后：Apps / Agents / Services" />

- 中文状态下按钮提示「切换到 English」；英文状态下为「Switch to 中文」。
- 只翻译界面文字；**空间、服务、会话等你自己起的名字不会被翻译**。

常用界面词对照：

| 中文 | English |
| --- | --- |
| 应用 / 智能体 / 服务 | Apps / Agents / Services |
| 新建服务 | New service |
| 服务开发 | Services development |
| 还没有选中服务 | No service selected |
| 总览 / 代码 / 版本管理 / 运行日志 | Overview / Code / Versions / Run logs |
| 固定标签页 | Pin tab |
| 折叠代码与预览 | Collapse Code and preview |
| 折叠应用导航 | Collapse Application navigation |
| 切换主题 | Toggle theme |

## 浅色 / 深色

语言按钮右侧的 **☀ / ☾** 是主题开关，在浅色与深色之间切换，三栏同时生效。图标显示的是**点击后将进入的模式**：浅色时显示月亮，深色时显示太阳。

<Shot src="/media/zh/shell-dark.png" caption="深色模式" />

::: tip
「设置 → General → 主题」还提供 **灰色** 和 **自定义** 两种选项。
:::

## 调整布局

- **折叠应用导航**：左上角按钮，收起整个导航栏。
- **折叠代码与预览**：右上角按钮，收起工作台。
- **拖动分隔条**：调整三栏宽度。

详见 [界面导览](/guide/interface)。
