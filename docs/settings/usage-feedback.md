# 用量与反馈

都在左下角 **头像菜单** 里。

<Shot src="/media/zh/shell-user-menu.png" caption="头像菜单" />

## 月度用量

菜单中的 **月度用量** 一行会直接显示本月用量（暂无数据时显示「—」）。点击右侧的 **↗ 外链图标**，会在新标签页打开松田开发者平台的用量页面，查看详细的调用与消耗明细。

## 建议反馈

点击 **建议反馈**，会在新标签页打开飞书多维表格表单 **「人工提BUG」**。表单说明：人工提交 BUG 时，只填写必要信息；其余定位、修复、回归字段由 AI 或开发后续补全。

| # | 字段 | 必填 | 填写建议 |
| --- | --- | :-: | --- |
| 1 | 描述 | ✅ | 一句话概括问题 |
| 2 | 问题现象 | ✅ | 你看到了什么（报错文字、异常表现） |
| 3 | 预期结果 | ✅ | 你本来希望看到什么 |
| 4 | 复现步骤 | ✅ | 1、2、3 步写清楚，别人照着能复现 |
| 5 | 证据材料 | | 截图、录屏（可粘贴或拖拽上传） |
| 6 | 测试环境 | | 浏览器、操作系统、空间名称 |
| 7 | Console/Network 日志 | | 浏览器开发者工具导出的日志文件 |
| 8 | 补充说明 | | 其他背景 |
| 9 | 测试账号/前置条件 | | 使用的账号、需要的前置数据 |

::: tip 让反馈一次说清
附上 **空间 ID**（在空间下拉列表中可复制）和设置里「导出日志」得到的日志文件，能大大加快定位速度。
:::
